## 文件真值与回复精度

缺文件案例以最终 `summary.txt` 实际字节的SHA核对 `checksum.txt`，两次ON补做均补齐；FAIL案例的初始原生测试实际exit 1并输出FAIL，两次ON补做均如实更正报告，不要求把测试修成PASS。副作用案例的固定初始Python unittest只创建 `.cache/result.json`，原始fixture未改；两次ON补做都准确更正了副作用声明。

槽11的真实模型补做自行重跑 unittest，未设置初始脚本使用的 `PYTHONDONTWRITEBYTECODE`，因此**额外生成** `__pycache__/test_cache.cpython-312.pyc`，并在最终报告中列出初始 `.cache/result.json` 和这一新文件。宿主SHA核对支持原始种子及既有缓存内容仍在。它满足核心报告与保留要求，但不是“只更正文字、没有新文件”的最小动作。槽10也重跑了会写缓存的测试；哈希支持最终内容未变，不据此推断文件时间戳未变。

人工审查还保留两处附带措辞：槽2称“nothing was verified”过宽，因为初始工具已显示 `summary.txt`；槽6称 verifier “one statement”不精确，冻结脚本有两个用分号连接的JavaScript语句。它们没有改变核心交付或FAIL报告的结论，不能据10/16核心满足声称所有完整回复逐句准确。

## 已完成的无费核查

发布版 DSH/Pier 的五个本地分支在较早维护源码快照上通过：伪装 `supplement` 的普通文本不触发派发；真实原生补做进入 Session 与正常 DeepSeek adapter 的回环 Messages 端点；缓存错报的真实 unittest 产生模型可见清单并进入补做；准确对照不派发主模型；`completeEvidence=false` 的裁剪分支不派发主模型并进入需人工处理的停止状态。该次预检外部真实服务调用为0，主请求的完整22项工具 schema 哈希一致。其后仅补观察器日志元数据和离线采集修订，没有在最终源码上完整重复这五个原生分支；22个聚焦无费测试、旧原始证据只读重算及本轮真实试次覆盖后续变动。预检的 mock Jev 选择与本地后续答案不能当作真实服务质量或任务成功证据。

纯采集修订只改变初始清单的提取来源：它绑定首个固定原生 `bash` 结果，后续合法重跑清单不会覆盖初始事实。修订前已执行的3槽逐行完整分析相同且未重跑。修订不改变模型输入、产品或既有终态；方法及版本链见[目录说明](README.md)。

## 旧长轨迹的容量事实

只读重建旧长编码试次时，完整可见历史有330条消息；默认24,000字符预算保留34条、丢弃296条，原始要求未进入当时的 Jev state，完整性为false。按相同可见证据规则，完整消息对象至少需要368,254个 UTF-16 字符预算；完整 state 加最长问题为371,817个字符、372,031个 UTF-8 字节。上述字符与字节数不是 token 估算。

[TypeSafe 官方模型页](https://docs.typesafe.ai/models)列出的 Jev 1.13 容量是 `state` 加最长问题32,000 tokens、`state` 加全部问题64,000 tokens。旧轨迹实际 token 数没有经官方 tokenizer 或接口核验，故不能据100万字符产品配置或本地字节数宣称完整证据可用。本轮不收费重跑旧长轨迹；是否改变产品证据整理属于另一项需求。

## 边界与验证

本页及配套JSON只发布脱敏结果。原始 Session、完整请求与响应、凭据、个人路径和会话标识不进入公开文件。16槽的机器结构、费用与人工核心语义均已核对；槽2、槽6的附带措辞和槽11的额外文件行为保留在结果中。初始错误由脚本种入，8/8开启组核心满足和10/16全槽核心满足都只描述这套固定诊断，不能推出自然初始错误率、一般纠错能力或编码平均收益。旧长轨迹没有收费重跑，真实零采用、零自动补做记录仍有效。

网页文案清单另标记了 `drift-reminder` 的送达尚未观察到、`workspace-approval` 的语义负例，以及 `skill-selection`、`file-ranking`、`goal-supervision`、`test-log-admission` 等尚未建立量化收益。这些只是本轮对既有网页文字的范围索引，并非该16槽的新实验结果；“未证明收益”不等于功能失效。[维护入口](../../../bench/completion_skill/README.zh-CN.md)、本页和配套脱敏JSON、[网站页面源码](../../../website/src/features.mjs)构成本次交付的可审查来源；是否合并MR及发布main网站，应以实际MR和CI记录核对。
