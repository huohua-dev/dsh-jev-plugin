# Typert build reference

The build copies the unmodified `lib/types/*.d.ts` declarations from the installed `@deepseek-ai/dsh-typert-protocol` development dependency into `src/`. The official Typert generator indexes these declarations through the Host project references while analyzing the external Jev plugin: it recognizes `Remote` and `TypertRemoteService` only when their declaring package is the workspace-registered `@deepseek-ai/dsh-typert-protocol`, which this private mirror provides. This directory is excluded from pnpm workspaces and the plugin package; ordinary protocol runtime imports continue to use the installed peer package; the generated Remote helper is vendored separately as described below.

The root `@deepseek-ai/dsh-typert-generator` development dependency is pinned to `0.2.2-alpha.2`, matching the DSH development baseline; it now moves with that baseline through [the version-update script](../../scripts/validation/bump-harness-version.mjs). Reflection uses `src/facade.d.ts`, emitted by [the preparation script](../../scripts/sync-typert-protocol.mjs) to export only `Remote` and `TypertRemoteService`. TypeScript still resolves the complete copied declarations. This limits the analyzed face without changing the official declarations or projecting the new `TypertRemoteInfo` / `TypertRemoteMethod` types onto a legacy format.

After generation, [the build helper](../../scripts/generated-remote-runtime.mjs) copies the installed official protocol package's `remote-info` JavaScript helper unchanged into the plugin output and rewrites both generated Host and Remote-client imports to that local copy. It rejects runtime module dependencies in the helper and unexpected generated import shapes. Vendoring this official helper lets the built package run on older Hosts that do not export the protocol's `remote-info` subpath; it does not replace the generated declarations or claim source-build compatibility with older development packages. Verify generated artifacts and compatibility checks after generator/protocol upgrades; no DSH source patch is part of this build.
